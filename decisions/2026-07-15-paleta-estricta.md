# Paleta cromática estricta (4 colores base)

**Fecha:** 2026-07-15  
**Estado:** Activo — fuente: `miplatita/design.md`

## Decisión

UI limitada a paleta de alto contraste. Sin colores secundarios ruidosos fuera de tokens definidos.

## Tokens principales

| Token | Hex | Uso |
|-------|-----|-----|
| lime-volt | `#87ea5c` | Acentos, tarjeta hero, CTAs móvil |
| forest-ink | `#083400` | Texto principal, header/footer móvil, botones primarios |
| fog | `#58717a` | Texto secundario, placeholders |
| surface-container | `#eeeeee` / `#f3f3f4` | Inputs, bordes, fondos neutros |

## Tipografía

- **Sora** — display, números grandes, marca
- **Inter** — cuerpo, tablas, forms

## Regla para agentes

No inventar colores ni fuentes. Cambios visuales → leer `skills/cambios-ui-design-system.md`.
